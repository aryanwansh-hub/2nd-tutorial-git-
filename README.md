# 2nd Tutorial – GitHub

This repository is created as part of my **second GitHub tutorial**.
The purpose of this tutorial is to practice and understand the basic concepts of **Git and GitHub**.

## 📌 About This Tutorial

In this tutorial, I am learning how to work with Git repositories and use GitHub to store and manage my code.

This demo will help me understand important Git concepts such as:

* Creating a Git repository
* Adding files to a repository
* Tracking changes
* Creating commits
* Writing meaningful commit messages
* Connecting a local repository with GitHub
* Pushing code from a local computer to GitHub
* Updating files and committing changes
* Managing different versions of a project

## 🎯 Purpose

The main goal of this project is to get more familiar with **GitHub and version control** through practical examples.

Instead of only learning the commands theoretically, this repository is being used as a small demonstration project where I can experiment with different Git commands and workflows.

## 🛠️ Technologies Used

* **Git** – For version control
* **GitHub** – For hosting and managing the repository
* **Markdown** – For writing this documentation

## 📚 What I Am Learning

Through this tutorial, I am practicing commands such as:

```bash
git init
git status
git add .
git commit -m "Initial commit"
git remote add origin <repository-url>
git push -u origin main
```

These commands are useful for creating a repository, tracking files, saving changes, connecting the local project to GitHub, and uploading the project.
